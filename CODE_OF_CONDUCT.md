# Code of conduct

We want OncoAgent to be built by people who respect each other and the patients the work is ultimately for.

- Be kind and specific. Critique code and evidence, not people.
- Assume good intent and ask before concluding.
- Credit sources and other people's work.
- Keep patient privacy sacred: never share real patient information, even in examples.
- No harassment, discrimination or personal attacks of any kind.

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Report unacceptable behaviour privately to the maintainers through the repository's private vulnerability reporting channel or the contact listed on the maintainers' GitHub profiles. Maintainers may remove comments, commits or contributors that break these rules.
